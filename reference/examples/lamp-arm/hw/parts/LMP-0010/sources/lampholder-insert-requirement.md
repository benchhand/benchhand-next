# LMP-0010 insert requirement

The user decided on 2026-10-27 that the head's lampholder thread is a heat-set M10x1 brass insert. `hw/decisions/DR-004.md` records the decision under "Lampholder insert".

The requirement is thread M10x1-6H, length 12.7 mm and knurl diameter 12.6 mm. No catalogue part meets it. The manufacturer and part number are open in `part.yaml`.
