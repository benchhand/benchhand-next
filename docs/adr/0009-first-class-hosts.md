# ADR-0009: Hosts tested and supported at release

Status: accepted. Source: [the approved plan](../design-plan.md).

## Context

We can't test every MCP host.

## Decision

Claude Code CLI, Claude Desktop, Codex CLI, the Codex / ChatGPT desktop app, OpenCode, Kiro CLI and Pi are tested and supported at release. Other hosts work through the fallbacks without a guarantee.

## Consequences

The install smoke matrix covers these seven.
