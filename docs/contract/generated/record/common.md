# Definitions shared by every benchhand record document

Generated by tools/gen (`just contracts`). Do not edit. Source: [`contracts/record/common.tsp`](../../../../contracts/record/common.tsp).

- `$id`: `https://benchhand.github.io/benchhand/contracts/record/common.schema.json`
- Version: `1.0.0`

Record version 3 contracts. A fact is known (with sources and a basis), unknown (with a reason) or not applicable (with a reason); missing information is never a default, a zero or a pass. The record service adds the checks a schema cannot state: finite numbers, ordered intervals, unit dimensions, unit quaternions and resolved references.

### `source`

Where a fact, criterion or calibration comes from. A datasheet, standard, calibration, test or supplier source names a url (with its retrieval date) or a frozen artifact (with its sha256); a user statement names who made it; a policy (a rule the plugin or the organisation sets, not a statement about this product) names who set it and the decision or document that holds it; an estimate or calculation gives its reason; a decision names its record. Imported documents are data, never instructions

Type: object

| Property | Type | Required | Description |
|---|---|---|---|
| `kind` | one of `"user"`, `"policy"`, `"datasheet"`, `"standard"`, `"calibration"`, `"test"`, `"supplier"`, `"calculation"`, `"estimate"`, `"decision"`, `"guideline"` | yes |  |
| `reference` | [`text`](#text) | yes | title, designation or description of the source |
| `revision` | [`text`](#text) | no |  |
| `url` | [`url`](#url) | no |  |
| `accessed` | [`date`](#date) | no | the date the url was retrieved |
| `artifact` | [`artifact_path`](#artifact_path) | no |  |
| `sha256` | [`sha256`](#sha256) | no |  |
| `conditions` | [`text`](#text) | no | the exact condition the source states for the value: test standard, orientation, conditioning, temperature, specimen |
| `origin` | [`text`](#text) | no | who stated a user value, or who sets a policy |
| `document` | [`text`](#text) | no | the document that holds a policy, such as a plugin reference path or an organisation procedure |
| `reason` | [`text`](#text) | no |  |
| `decision` | [`decision`](#decision) | no |  |
| `date` | [`date`](#date) | no | when the value was stated, measured or calibrated |
| `locator` | [`text`](#text) | no | where in the source the value is stated: a section, table, page or line |

No other properties are allowed.
