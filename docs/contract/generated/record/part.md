## Definitions

### `intent`

Record version 2 manufacturing intent: what the part does, the qualified material profile, the service it sees, its critical surfaces and its complete ordered route. make_buy and procurement.mode stay the sourcing authority; manufacture stays the manufacturing-state authority. A sole solid is the implicit main component; a part with several solids lists components

Type: object

| Property | Type | Required | Description |
|---|---|---|---|
| `functions` | array of [`function_entry`](common.md#function_entry) or [`fact_unknown`](common.md#fact_unknown) | yes |  |
| `material_profile` | [`profile_id`](common.md#profile_id) or [`fact_open`](common.md#fact_open) | yes | a profile id in manufacturing/materials.yaml |
| `color` | string | no | The part's print colour as an sRGB hex string #RRGGBB (for example #FF8000 for orange). 3MF export uses it as the part's display colour `maxLength: 7`, `pattern: "^#[0-9A-Fa-f]{6}$"` |
| `selection` | [`semantic_id`](common.md#semantic_id) | no | the selection.yaml candidate this intent implements |
