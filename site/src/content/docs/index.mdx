## What benchhand is

benchhand is an MCP server for mechanical design with an AI agent.
Your agent host starts it, and it runs the design process: requirements, concept, design, verification and release.
It keeps each decision, check and approval in the project's record under `hw/`.

- **One interface.** You run the workflow through MCP. The `benchhand` command is a thin launcher and admin tool.
- **Guidance from the server.** The agent calls `flow.guide`, and the server answers with the current stage, its tools and the next action.
- **Gates guide, they don't guard.** Each gate asks for your approval by default. A project can set a gate to `chat` or `auto` in `hw/policy.yaml`, and the record keeps every relaxation.
- **Providers for everything.** Kernels, FreeCAD, solvers, renderers, process checks and storage plug in behind one provider protocol.

## Who it is for

- Makers and engineers who design parts with an agent and need a record they can audit.
- Teams who write providers or policies for their own processes.
