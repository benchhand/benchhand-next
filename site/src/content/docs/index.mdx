## The documentation

- [Get started](/getting-started/install/): install benchhand, start a first project and take a first part to a STEP file.
- [Guides](/guides/tutorials/bracket/): worked tutorials, and the tasks of migrating a prototype record, writing and testing rules, adding providers and troubleshooting.
- [Concepts](/concepts/process/overview/): the design process and its gates, the record, policy, providers, manufacturing and the clients.
- [Reference](/reference/): the MCP tools, the CLI, the flow, the contracts and their JSON Schemas, and the Python API.
- [Contributing](/contributing/): set up the repository, run the checks, and find the design plan and the decision records.
