- [MCP tools](/reference/mcp-tools/): the tools, resources, prompts and Apps of the benchhand MCP server, and the result envelope every tool returns.
- [CLI](/reference/cli/): every `benchhand` command, with its arguments and options.
- [Flow](/reference/contracts/flow/): the flow definition, `flow.yaml`, with its stages, gates and the rule lists it references.
- [Contracts](/reference/contracts/): one page per record, job, finding and provider-protocol contract, with its fields and version, and the JSON Schema that this site serves for it.
- [Python API](/reference/python-api/): the public API of `benchhand-contracts`, `benchhand-provider` and `benchhand-sdk`.

The CLI, contract and Python API pages are generated from the source, so they match the code they describe.
