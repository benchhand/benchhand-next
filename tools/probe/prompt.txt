This is a capability test of an MCP server named "probe". Call its tools once each, in this order: probe_capabilities, probe_image, probe_progress (seconds=5), probe_form, probe_app, then probe_timeout with seconds=75. If you can list or read MCP resources, read probe://readme. Say whether a prompt named probe_prompt is available to you. Do not use any other tools. Then write your report: for each call, whether it succeeded, what content types you received (text, image, resource link), whether you could see the image and its colours, and any error or timeout message, verbatim. Finally, call probe_report with that full report as its `report` argument, and show the report here too.
